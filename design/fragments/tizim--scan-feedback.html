Kamerada nima boshqacha

Kamera doim qorong'i
  • Doira chizilmaydi. Kamerada ko'z ekranda — ramka belgisi (.el-cam-mark) doira vazifasini bajaradi, matn kamera xabarida. Katta doira ramkani yopib, keyingi posilkani nishonga olishga xalaqit beradi.
  • Parda kamera ustida. Rang butun kamera yuzasini — yuqori va pastki panellarni ham — qoplaydi. Kamera doim qorong'i, shuning uchun tungi qiymat olinadi: O'rtacha 0,26.
  • Vaqt kameraga mos. Kamera pauzasi 700 ms; parda 970 ms. Pauza tugagach yangi skan pardani darhol yangilaydi — ikkinchi parda kutilmaydi.
  • Kamera oynasi (desktop, planshet). Parda faqat kamera oynasini qoplaydi; o'ng panel va ostidagi sahifa bo'yalmaydi. USB skan esa oynadan tashqarida butun ekranni bo'yaydi.

type Note = { hz: number; at: number; ms: number; peak: number };

};
type Signal = "success" | "duplicate" | "warning" | "error";
// "missing" → "error"

  ({ hz, at, ms, peak });

Slayder 0–100%, qadam 10. Eshitish egri chizig'i bo'yicha: gain = (v / 100)^1,6. 60% da muvaffaqiyat cho'qqisi ≈ −13 dBFS, 100% da −6 dBFS. Tizim ovozi o'chiq bo'lsa, ilova uni yoqmaydi.

Agar fayl bilan qilinsa

  • Sukut — Web Audio: fayl yuklanmaydi, kechikish ≈ 5 ms, oflaynda ham ishlaydi. Fayl faqat ovoz dizayneri yozib bersa.
  • Format: WAV 48 kHz / 24 bit mono — manba; ilovaga MP3 emas, .m4a (AAC-LC 96 kbit/s mono) yoki .ogg Opus — MP3 boshida 25 ms jimlik qo'shadi.
  • Davomiylik: muvaffaqiyat ≤ 160 ms, takroriy ≤ 100 ms, ogohlantirish ≤ 200 ms, xato ≤ 250 ms; boshidagi jimlik ≤ 5 ms, oxirida 20–30 ms so'nish.
