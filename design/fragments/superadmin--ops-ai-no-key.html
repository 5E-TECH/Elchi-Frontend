Kalit qo'shish
Qanday kalit kerak
  • Oddiy API kaliti («sk-ant-» bilan boshlanadi). Admin kaliti va Claude obunasi tokeni ishlamaydi.
  • Console'dagi bitta ish maydoni ichida yaratilgan kalit — test server uchun alohida ish maydoni, oylik xarajat limiti bilan.
  • Saqlashdan oldin kalit Anthropic'da bepul tekshiriladi — token sarflanmaydi.

Kalit shifrlangan holda saqlanadi va hech qachon qayta ko'rsatilmaydi. Elchi'dan o'chirish kalitni Anthropic'da bekor qilmaydi — kalit sizib chiqsa, Anthropic Console'da o'chiring.
