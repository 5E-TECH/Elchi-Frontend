# Maket → kod xaritasi (CODE-MAP)

Maketlar `design/kit/helmet.html` dagi `el-*` klasslari bilan chizilgan. Bu klasslar **ilovada yo'q** — maketdan
JSX'ga klass nomini ko'chirmang, shu jadval bo'yicha tarjima qiling.

> ⚠️ **Nom to'qnashuvi.** `src/index.css` da maket bilan bir xil prefiksli **eski (v1)** klasslar bor:
> `.el-card` (gradient + katta soya), `.el-card-soft`, `.el-surface-page`, `.el-glass-control`, `.el-segmented`,
> `.el-segmented-button(-active)` (gradient), `.el-muted-text`, `.el-soft-text`. Ular v2 **emas**. Yangi kodda
> `className="el-card"` yozsangiz maketdagi kartani emas, eski gradientli kartani olasiz. Yangi kodda ularni
> ishlatmang va yangi joyga ko'chirmang.

**Tanlash tartibi** (har element uchun):
1. «1-bosqich» ustunida primitiv yozilgan bo'lsa — o'shani ishlating, Tailwind'ni qo'lda yozmang. 1-bosqich
   **tayyor**: `src/shared/ui/primitives` (barrel, faqat nomli eksport) — `Button`, `IconButton`, `Spinner`, `Badge`,
   `StatusBadge`, `Card`, `StatCard`, `PageHeader`, `Tabs`, `SegmentedControl` va ton klasslari (`tone.ts`:
   `TONE_SOFT`, `TONE_FG`, `TONE_SOLID`, `TONE_RING`). Buyurtma holati — `OrderStatusBadge` + `ORDER_STATUS_REGISTRY`
   (`src/entities/order`). Formatlovchilar: `formatDateTimeLocalized` / `formatDateLocalized` / `formatTimeLocalized`
   (`src/shared/lib/formatDateTime.ts`), `formatPhone` / `toTelHref` (`formatPhone.ts`), `formatSignedMoneyLocalized`
   (`formatMoney.ts`), klass birlashtirish `cx` (`cx.ts`). Namunasi: `/ops/ui-kit` (superadmin).
2. 3-bosqich ham **tayyor** (o'sha barrel; namunasi `/ops/ui-kit?section=forms|select|date|dialog|feedback|states`):
   forma — `Field` + `TextInput` / `Select` / `DateRange` / `DateInput` / `Calendar`; oyna — `Dialog`, tasdiq —
   `ConfirmDialog` / `useConfirm()`; xabar — `notify()` (`src/shared/lib/notify.ts`) + `Toaster`; holatlar —
   `EmptyState`, `ErrorState`, `Skeleton*`, `QueryBoundary`. antd `message` / `notification` / `Popconfirm` /
   `Modal.confirm` va brauzer `confirm()` — ESLint taqiqlaydi. Ustunda «—» bo'lsa, shu jadvaldagi Tailwind
   klasslarini yozing (faqat tokenlar). **Ro'yxat standarti (4-bosqich):** jadval — `DataTable`, sahifalash —
   `Pagination` (o'sha barrel, `import { DataTable, Pagination } from "…/shared/ui/primitives"`; namunasi
   `/ops/ui-kit?section=table`; birinchi iste'molchi — `/orders`). `shared/components/Table` va
   `shared/components/pagination` (v1) yangi kodda ishlatilmaydi.
3. «Bugun bor» ustunidagi mavjud komponentni **xatti-harakati uchun** qayta ishlating (fokus tuzog'i, portal,
   pagination mantig'i, skaner). Ularning ko'pchiligining ko'rinishi hali v1 (`bg-main`, `text-maindark`, `bg-white`).
   Tegsangiz, ko'rinishini shu jadval bo'yicha v2 ga keltiring. Eski ko'rinishni yangi joyga nusxalamang.
   1-bosqich almashtirgan v1 modullari yangi kodda import qilinmaydi (qo'riqchi `v1-helper`):
   `shared/components/button` → `Button`, `shared/ui/StatusBadge` va `pages/orders/list/OrderStatusBadge` →
   `StatusBadge` / `OrderStatusBadge`, `shared/config/statusColorMap` → `statusRegistry` + `tone.ts`,
   `shared/lib/formatDate` → `formatDateTimeLocalized`.

Primitivi yo'q qism uchun qo'lda yozilgan retsept (masalan gauge) **shu jadvaldagi klasslar bilan aynan**
yoziladi — har kim o'z variantini o'ylab topmaydi. Pastki varaqa, bo'sh/xato/yuklanish holati, forma maydoni,
tasdiqlash oynasi va xabar endi qo'lda yozilmaydi — 3-bosqich primitivlari.

Barcha klasslar Tailwind v4 (`@tailwindcss/vite`) va `src/index.css` dagi `@theme` tokenlari bilan tekshirilgan.
Faylingizdagi eski rang/nom/o'lchamlar va ularning v2 o'rnini bosuvchisi: `npm run design:guard -- <fayl>`.

### 0.3 Moslashuvchanlik: konteyner so'rovlari → Tailwind breakpointlari

Maket `.el` ildizida **container query** ishlatadi (`@container el (max-width:1023px)` va `(max-width:767px)`).
`.el` ildizi butun ilova kengligi bo'lgani uchun ilovada **viewport breakpointlari** aynan teng keladi:
Tailwind `lg` = 1024, `md` = 768.

| Maket | Ilova | Ma'nosi |
|---|---|---|
| `@container el (max-width:1023px)` | `max-lg:` | planshet va telefon (< 1024) |
| `@container el (max-width:767px)` | `max-md:` | faqat telefon (< 768) |
| `.el-hide-tablet` | `max-lg:hidden` | < 1024 da yashirin (jadvalning ikkinchi darajali ustuni: `th` va `td` ikkalasiga) |
| `.el-hide-mobile` | `max-md:hidden` | < 768 da yashirin (jadval, tooltip, kursor chizig'i) |
| `.el-show-mobile` | `hidden max-md:flex` | faqat telefonda (kartalar ro'yxati, qisqa kodlar) |
| `.el-show-tablet` | `hidden max-lg:inline-flex` | < 1024 da (menyu tugmasi) |

`sm:` (640) v2 da telefon chegarasi **emas**. Telefon = `max-md:`. Maket telefonda o'zi qiladigan narsalarni kodda
qo'lda yozasiz:

- tugma, maydon, chip, sahifa raqami: `max-md:min-h-11`; ikonka-tugma `max-md:size-11`; tab `max-md:h-12`;
- `.el-pagehead` amallari to'liq enli: `max-md:w-full max-md:[&>*]:flex-1`;
- har `.el-overlay > .el-dialog` telefonda **pastdan chiquvchi varaqa** (2.8-bo'lim);
- sahifa sarlavhasi 20/28 (`max-md:text-xl`), sahifa oraliqlari 16 (`max-md:gap-4`).

### 0.4 Maket va ilova tokenlari

Holat ranglari (`success`, `warning`, `danger`, `info` va ularning `-fg` / `-soft`) ikkala mavzuda maket bilan **bir
xil** (1-bosqichda tungi qiymatlar maketga moslashtirildi: `#4fc58e`, `#f1b24e`, `#ff7182`, `#6bb6f3`). To'liq rangli
fon har doim `on-solid` matn bilan: `bg-success text-on-solid`, `bg-danger text-on-solid` — ikkala mavzuda AA.
`text-white` / `text-primary` holat foni ustida ishlatilmaydi (tungida o'qilmaydi).
